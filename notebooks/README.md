# Notebooks Jupyter

Ce répertoire contient les notebooks Jupyter pour l'exploration et la modélisation.

## Fichiers

### 01_EDA.ipynb
Exploration et Analyse des Données (Exploratory Data Analysis)

**Contenu**:
- Chargement des données
- Statistiques descriptives
- Visualisations
- Analyse des valeurs manquantes
- Distribution des variables
- Corrélations
- Insights préliminaires

### 02_modeling.ipynb
Modélisation et Évaluation

**Contenu**:
- Préparation des données
- Entraînement des modèles
- Évaluation comparative
- Sélection du meilleur modèle
- Analyse des résultats
- Recommandations

## Comment utiliser

```bash
# Installer Jupyter
pip install jupyter

# Lancer Jupyter
jupyter notebook

# Ouvrir les notebooks
```

---

**Note**: Les notebooks ne sont pas versionés (voir `.gitignore`). Ils sont utilisés pour l'exploration interactive.
